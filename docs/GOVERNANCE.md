## ⚖️ Decision Process
- **Minor Changes:** (Fixes, docs) Direct PR.
- **ISA/Protocol Changes:** Require update to `BYTECODE.md` and consensus from maintainers.
- **FFI Stability:** Changes to `vm-ffi` must ensure backward compatibility for the Python bindings.
